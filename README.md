# 边缘海克斯 | RimHex

为殖民地和指定殖民者选择永久强化，收集遗物，组合流派、进化与战技。

**当前发布版本：0.37.26** · RimWorld 1.6 / 1.7 · 需要 Harmony

[Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3799235195) · [反馈 Bug 或建议](https://github.com/ShaunAsherLeo-oss/RimHex/issues/new/choose) · [查看已有反馈](https://github.com/ShaunAsherLeo-oss/RimHex/issues)

## 下载与安装

推荐在工坊订阅。也可以点击本页 **Code → Download ZIP**，解压后将里面的 `RimHex` 文件夹放入 RimWorld 的 `Mods` 目录，在游戏模组列表中启用，并将 Harmony 排在 RimHex 前面。更新时退出游戏，再替换原来的 RimHex 文件夹。

这里的 `RimHex/` 与当前工坊上传用的安装包完全一致。请避免同时启用本地版和工坊版。

## 反馈

点击 **[提交反馈](https://github.com/ShaunAsherLeo-oss/RimHex/issues/new/choose)**，选择“Bug 反馈”或“建议与体验反馈”。提交需要登录 GitHub。

反馈 Bug 时请写明 RimWorld 和 RimHex 版本、涉及的卡牌或遗物、操作步骤，以及预期和实际结果。截图、Player.log 和启用的模组列表可以直接附在反馈中。若反馈已存在，可以在原帖补充。
